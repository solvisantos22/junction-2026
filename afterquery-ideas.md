# AfterQuery — shortlist for tonight

Goal: a convincing demo and a competitive submission. Ideas are provisional.

[The challenge](https://hackjunction.app/participate/45/challenges/328): build an environment where a frontier agent struggles, demonstrate a stronger reference, and make rewards hard to exploit.

**Scoring:** gap 30%, fair difficulty 30%, reward integrity 25%, reproducibility 15%. Training is optional. Judges rerun both approaches, test doing nothing/stopping early, and hunt exploits.

**1. ColdChain — my current favourite**
Two vehicles, eight perishable deliveries, limited capacity and a disruption. Taking an easy delivery can prevent an urgent one later. Demo: agent vs planner on a map; reward actual on-time deliveries.
**Fit:** our backend, optimization and simulation skills.
**Risk:** the agent might solve it with a routing script; test the gap early.

**2. BatchPilot — strongest control angle**
Produce three acceptable batches in a simulated heating/cooling process. Demo: agent vs predictive controller; delayed reactions spoil batches. Reward completed, valid batches.
**Fit:** Manh’s control expertise plus our math and agent experience.
**Risk:** the process must be credible, not an arbitrary puzzle.

**3. RecoveryRoom — strongest backend angle**
Restore a simulated service without losing or duplicating jobs. Demo: agent vs recovery policy; clearing the queue cannot count as success.
**Fit:** Sölvi and Kristján’s automation experience.
**Risk:** infrastructure scope and existing incident-response benchmarks.

**Recommendation:** ColdChain, then BatchPilot. No performance gap is proven; both approaches must get the same information.
