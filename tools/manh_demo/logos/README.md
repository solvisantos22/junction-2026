# Marks of the labs whose models appear in the demos

The logos themselves are trademarks of Anthropic, OpenAI and Google. They are used here only to name the maker of a model shown on screen; no endorsement is implied. Only Claude appears in `manh_demo_1`; the others are here for the demos to come.
