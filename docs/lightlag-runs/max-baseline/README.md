# MAX-map model baseline

A freeze point for the MAX map: Claude models write one program each, from one request, and it plays
superhard and fair MAX worlds. Frozen 2026-11-14 21:34 Helsinki. Generated by `python3 -m lightlag_traverse_max.oneshot
report`; the method and every command are in [`lightlag_traverse_max/oneshot.py`](../../../lightlag_traverse_max/oneshot.py).

## What is frozen

- **Superhard worlds:** 505, 509, 515. manh_max scores 0.199, 0.180 and 0.094 on the MAX map (the hardest of the 24 is 515; 509 is the only one of the 8 hardest where it still gets home). All 8 worlds under 0.2 were 503 504 505 509 515 516 517 518; the 9th hardest scored 0.291.
- **Fair worlds:** 500, 510, 520. manh_max scores 0.455, 0.481 and 0.529 on the MAX map and gets home, keeping 82%, 99% and 99% of its normal-map score; the three highest MAX scores of the 24.
- **Anchor:** 2026, the task's world, as an anchor next to Kristján's normal-map baseline; in neither group.
- **Where they come from:** The 24 worlds 500-523 (Manh's claimed range), each played once on both maps by all four scripted players at full budgets and never used for tuning. Manh picked both groups from them by manh_max's score on the MAX map, after the first freeze and before any request was sent.
- **Request:** [`request.md`](request.md), sha256 `8b0c412f40f21cc0c5bc468372d98baac8d85af324fc2a84461182fd61ab8699`: Kristján's one-request text with the MAX map's rules, map
  and example world (99991), plus a section on what the MAX map changes.
- **Models:** `claude-haiku-5-5`, `claude-sonnet-5-5`, `claude-opus-5-5`; 3 replies each, effort `medium`, adaptive thinking, at most 128000 output tokens,
  no retries, no fallback model. A reply counts as it came; one without a program scores 0 everywhere.
- **Playing:** every program plays every world once on the MAX map in `lightlag_traverse_max.sandbox`
  (Kristján's worker under bubblewrap; it reproduces his Docker run of the normal-map Opus program byte for byte).
- **The mission's code** is pinned by sha256 in [`freeze.json`](freeze.json).
