public-range sensitivity diagnostic. No model/API calls or candidate source
changes. The scripts write only the output path requested; choose a temporary
path to preserve the retained evidence.

Ground results are normalized by each mission's available target value, not an
optimal achievable reference. The prior diagnostic also changes initialization
and planning; it is not a clean clamp ablation or a new competitive reference.
All negative outcomes are retained. Ground JSON includes hashes for 61 supporting
Python files and runtime versions. Full ground replays are regenerated by the
script and hashed, not duplicated here. Sample-chain complete plans remain in
the original frozen artifacts.

The pilot audit validates the saved behavior and grades under the current
implementation. Its original task hashes are explicitly stale and added source
files are missing from its manifest, so it does not verify a complete frozen
task package. That limitation is retained in the JSON and assessment.

## Reproduce

Run from the repository root with **Python 3.12** and **NumPy 2.3.4**, as tested
for the ground-control reproductions. The sample-chain audit needs Python 3.10+
and only the standard library; it was tested on 3.12.16. The machine's default
Python 3.9.6 cannot execute its `int.bit_count` calls. The ground environment's
six existing tests themselves require only the standard library.

With the appropriate interpreter selected:

```sh
python3.12 -m unittest discover -s tests/certified_challenge_probe -v
python3.12 -m unittest discover -s tests/lightlag_shift -v
python3.12 docs/prototype-assessment/audit_sample_chain.py --output /tmp/sample-chain-audit.json
python3.12 docs/prototype-assessment/audit_ground_shift.py --output /tmp/ground-shift-audit.json
python3.12 docs/prototype-assessment/audit_ground_prior.py --output /tmp/ground-prior-audit.json
python3.12 docs/prototype-assessment/audit_rule_change.py --output /tmp/rule-change-audit.json
python3.12 docs/prototype-assessment/audit_ground_pilot.py --output /tmp/ground-pilot-audit.json
```

The recorded checks are 10/10 sample-chain tests, 6/6 original ground-change
tests and 18/18 shift tests after the rule-change update (including those six).
Exact scores, plans and replay hashes reproduce in the tested runtime; elapsed
time and observed repository revision may change. The ground scripts' copied
portable versions were rerun: all 480 per-case records and replay hashes matched
their initial runs. No additional search or tuning was performed.
